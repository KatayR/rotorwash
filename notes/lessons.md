# Lessons

## Ring course layout (2026-10-21)

- A ring has to face the leg that leads into it. Turning it to the line between the rings before and after looks broken wherever the course turns sharply.
- Turning rings the right way does not fix a zig-zag route. With a turn of about 117° between legs, the next ring still looks wrong from where you leave the last one. Keep every turn between legs under about 45°. Add a ring to split a turn instead of re-aiming rings.
- Before publishing a new route, check by script: the turn at each ring, each ring's height above the ground, the clearance along each leg, and that flying the whole course passes every ring.
- Place each ring a set height above the terrain, and lift it only to clear a roof right under it. Basing the height on the tallest thing nearby put one ring 107 m up over a tower.
- When the course changes, bump the storage key for the best time, because a time set on the old course is not comparable.
